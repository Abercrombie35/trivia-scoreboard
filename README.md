# Trivia scoreboard

Live scoreboard: https://abercrombie35.github.io/trivia-scoreboard/

An open page refreshes on its own about a minute after each update.

## For co-hosts recording scores

1. Accept the GitHub collaborator invite for this repo.
2. In the Claude app (Code tab) or at https://claude.ai/code, start a new session with
   the repository **Abercrombie35/trivia-scoreboard** selected.
3. Tell Claude the scores in plain words, e.g. `Round 3: Bears 8, Pints 6.5, T3 7`.
   Claude follows `CLAUDE.md` and publishes through `score.py`.
